Audit decimal commas in prose and tables where applicable, leading zeroes for values below 1, spaces between values and units, symbols, percentages, scientific/Latin italics, and consistent terminology. Follow the applicable official standard and scope. Critical rule: never alter numeric syntax inside R code to force decimal commas.
