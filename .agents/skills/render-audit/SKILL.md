---
name: render-audit
description: Verify rendered Quarto DOCX output, structure, pagination, and layout.
---

After a render, verify successful completion and the expected output file. Record page count using Word as the editorial reference. Check all 8 visible parts, continuous chapters 1–29, TOC, tables, figures, code blocks, equations, bibliography, blank pages, page breaks, clipping, and overflow. Report page-specific visual defects with type and location. Distinguish structural checks from visual inspection; do not claim visual PASS without inspecting rendered pages.
