# Checklist maestra — paquete de envío Editorial UNL

Estados permitidos: **PASS**, **REVIEW**, **BLOCK**.

## A. Manuscrito

| Control | Estado |
|---|---|
| Naturaleza de la obra confirmada por el autor: **Libro académico** | PASS |
| Manuscrito definitivo en un único Word editable | REVIEW |
| Revisión de estilo, gramática y ortografía completada | REVIEW |
| Estructura ajustada a la plantilla UNL aplicable | REVIEW |
| Tamaño y márgenes ajustados a la tipología/plantilla oficial aplicable | REVIEW |
| Citas y referencias en APA 7 | REVIEW |
| Bibliografía >5 años no supera el 20%, salvo justificación por fuentes clásicas/normativas | REVIEW |
| Correspondencia completa entre citas en texto y bibliografía | REVIEW |
| Sistema Internacional de Unidades e INEN aplicados | REVIEW |
| Separador decimal con coma cuando corresponda | REVIEW |
| Tablas editables; ninguna tabla convertida en imagen | REVIEW |
| Figuras originales/autorizadas y ≥300 ppp | REVIEW |
| Figuras y tablas numeradas, citadas y con títulos/fuentes correctos | REVIEW |
| Ecuaciones editables; no capturas de pantalla | REVIEW |
| Bibliografía y citas cruzadas auditadas | REVIEW |
| Resumen editorial para contraportada ≤180 palabras | REVIEW |
| Tres imágenes propuestas para portada, nítidas y con derechos de uso | REVIEW |

## B. Expediente administrativo

| Control | Estado |
|---|---|
| Solicitud de publicación completada y firmada | REVIEW |
| Cesión de derechos completada y firmada por autores requeridos | REVIEW |
| Formulario de presentación completado | REVIEW |
| Documento de identificación de cada autor/editor | BLOCK |
| Micro-CV de cada autor/editor con fotografía | BLOCK |
| Autor/a de correspondencia definido | REVIEW |
| Información de autores consistente entre manuscrito, formularios y OMP | REVIEW |
| Nomenclatura de archivos clara y descriptiva | REVIEW |

## C. Transparencia y ética

| Control | Estado |
|---|---|
| Originalidad e ineditud verificadas | REVIEW |
| Derechos de terceros verificados | REVIEW |
| Permisos/licencias de imágenes y material externo documentados | REVIEW |
| Declaración de uso de IA incluida al final, después de referencias, cuando corresponda | REVIEW |
| Declaración IA documenta herramienta, propósito, instrucciones/prompts, integración, revisión humana y limitaciones | REVIEW |
| Toda salida asistida por IA revisada y validada por autores | REVIEW |
| Ninguna referencia incorporada sin verificación de existencia y correspondencia | REVIEW |

## D. Metadatos OMP

| Control | Estado |
|---|---|
| Título definitivo | REVIEW |
| Subtipo/formato editorial UNL compatible con **Libro académico** confirmado | BLOCK |
| Palabras clave | REVIEW |
| Resumen | REVIEW |
| Capítulos registrados cuando aplique | REVIEW |
| Colaboradores/autores en orden correcto | REVIEW |
| Autor de correspondencia marcado | REVIEW |
| Nota al editor preparada si corresponde | REVIEW |
| Revisores sugeridos evaluados por pertinencia y ausencia de conflictos | REVIEW |

## E. Carga y envío

| Control | Estado |
|---|---|
| Manuscrito marcado como “Manuscrito de libro” | REVIEW |
| Documentos administrativos cargados como “Otro” | REVIEW |
| Todos los archivos del expediente presentes | BLOCK |
| Tres propuestas de portada presentes | REVIEW |
| Resumen de contraportada ≤180 palabras presente | REVIEW |
| Revisión final de metadatos realizada | REVIEW |
| Auditoría final sin BLOCK | BLOCK |
| Confirmación de “Envío completo” archivada | REVIEW |

## Regla de cierre

**SUBMISSION READY** solo puede declararse cuando no exista ningún control crítico en **BLOCK** y se haya efectuado una auditoría final de integridad, reproducibilidad, metodología, contribución y ajuste editorial.

La recomendación de que la bibliografía con más de cinco años no supere el 20% se trata como un criterio editorial a auditar, no como una regla para eliminar mecánicamente fuentes clásicas, metodológicas, normativas o históricas necesarias.
