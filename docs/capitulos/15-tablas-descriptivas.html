18  Tablas descriptivas

Objetivos de aprendizaje

Al finalizar este capítulo, el lector será capaz de:

  • Comprender la importancia de las tablas descriptivas en la investigación científica.
  • Construir tablas descriptivas reproducibles utilizando R y Quarto.
  • Elaborar tablas de variables numéricas y categóricas.
  • Generar tablas cruzadas para explorar asociaciones entre variables.
  • Aplicar buenas prácticas para la presentación de resultados estadísticos.
  • Preparar tablas listas para informes, tesis y artículos científicos.

18.1 Introducción

Las tablas constituyen uno de los mecanismos más utilizados para comunicar resultados estadísticos en artículos científicos, tesis, informes técnicos y documentos institucionales.

Una buena tabla permite resumir grandes volúmenes de información de forma clara, precisa y reproducible. Por el contrario, una tabla mal construida puede dificultar la interpretación de los resultados y reducir el impacto de una investigación (Cleveland, 1993; Healy, 2018).

En el contexto de la investigación reproducible, las tablas deben generarse automáticamente a partir de los datos y del código utilizado en el análisis. Esto evita errores manuales, facilita actualizaciones y garantiza la trazabilidad de los resultados (Gandrud, 2015; Peng, 2011).

En este capítulo aprenderemos a construir tablas descriptivas utilizando información real de la ESPAC 2025.

18.2 Cargando la base de trabajo

library(dplyr)
library(knitr)
library(here)

base_analitica <- readRDS(
  here(
    "datos",
    "procesado",
    "ESPAC_2025",
    "sunac_transformado.rds"
  )
)

18.3 ¿Por qué son importantes las tablas?

Las tablas permiten:

  • Resumir grandes cantidades de información.
  • Comparar grupos de observación.
  • Identificar patrones y diferencias.
  • Facilitar la comunicación de resultados.
  • Documentar evidencia estadística de forma reproducible.

La mayoría de artículos científicos presentan resultados descriptivos inicialmente mediante tablas antes de introducir modelos estadísticos más complejos (Healy, 2018).

18.4 Principios de una buena tabla

Una tabla académica debe cumplir varios criterios básicos:

  • Tener un título claro.
  • Mostrar únicamente información relevante.
  • Mantener un formato consistente.
  • Utilizar nombres comprensibles.
  • Incluir unidades cuando sea necesario.
  • Ser autoexplicativa.

18.5 Construcción de una tabla simple

Podemos comenzar creando una tabla que muestre las dimensiones generales de la base.

data.frame(
  Registros = nrow(base_analitica),
  Variables = ncol(base_analitica)
) |>
  kable(
    caption = "Dimensiones generales de la base analítica"
  )

La tabla resume el tamaño de la base utilizada durante el análisis.

18.6 Tablas descriptivas para variables numéricas

Las variables numéricas suelen describirse mediante:

  • Media.
  • Mediana.
  • Desviación estándar.
  • Valor mínimo.
  • Valor máximo.

Estas estadísticas permiten resumir el comportamiento general de una variable (Moore et al., 2017).

18.7 Tabla descriptiva básica

Analizaremos la variable supertotal.

data.frame(
  Variable = "Superficie total",
  Media = mean(
    base_analitica$supertotal,
    na.rm = TRUE
  ),
  Mediana = median(
    base_analitica$supertotal,
    na.rm = TRUE
  ),
  Desviacion = sd(
    base_analitica$supertotal,
    na.rm = TRUE
  ),
  Minimo = min(
    base_analitica$supertotal,
    na.rm = TRUE
  ),
  Maximo = max(
    base_analitica$supertotal,
    na.rm = TRUE
  )
) |>
  kable(
    digits = 2,
    caption = "Estadísticas descriptivas de la superficie total"
  )

Esta tabla resume los principales indicadores descriptivos de la variable.

18.8 Tabla descriptiva de múltiples variables

En la práctica, generalmente analizamos varias variables simultáneamente.

data.frame(
  Indicador = c(
    "Media no ponderada",
    "Media ponderada"
  ),
  Valor = c(
    mean(
      base_analitica$supertotal,
      na.rm = TRUE
    ),
    weighted.mean(
      x = base_analitica$supertotal,
      w = base_analitica$fact_exp_fin,
      na.rm = TRUE
    )
  )
) |>
  knitr::kable(
    digits = 2,
    caption = "Media no ponderada y ponderada de la superficie total"
  )

Observe cómo una sola tabla resume múltiples variables de interés.

18.9 Interpretación de tablas descriptivas

La interpretación debe acompañar siempre a las tablas.

Por ejemplo:

  • La media representa el comportamiento promedio.
  • La mediana indica el valor central.
  • La desviación estándar refleja la dispersión.
  • Diferencias importantes entre media y mediana pueden sugerir asimetría.

La tabla debe ser el punto de partida para la interpretación y no un fin en sí misma.

18.10 Tablas de frecuencia

Las variables categóricas requieren otro tipo de resumen.

Para estas variables se utilizan tablas de frecuencia.

Analicemos la variable:

tamano_upa

18.11 Frecuencia absoluta

base_analitica |>
  count(
    tamano_upa
  ) |>
  arrange(
    desc(n)
  ) |>
  kable(
    caption = "Frecuencia absoluta del tamaño de UPA"
  )

Esta tabla muestra cuántas observaciones pertenecen a cada categoría.

18.12 Frecuencia relativa

Los porcentajes suelen ser más informativos.

base_analitica |>
  count(
    tamano_upa
  ) |>
  mutate(
    porcentaje =
      round(
        n / sum(n) * 100,
        2
      )
  ) |>
  arrange(
    desc(n)
  ) |>
  kable(
    caption = "Frecuencia relativa del tamaño de UPA"
  )

La frecuencia relativa facilita la comparación entre categorías.

18.13 Frecuencias acumuladas

También podemos construir frecuencias acumuladas.

base_analitica |>
  count(
    tamano_upa
  ) |>
  mutate(
    porcentaje =
      round(
        n / sum(n) * 100,
        2
      ),
    acumulado =
      cumsum(
        porcentaje
      )
  ) |>
  kable(
    digits = 2,
    caption = "Frecuencias acumuladas del tamaño de UPA"
  )

Las frecuencias acumuladas permiten conocer qué porcentaje de observaciones se concentra hasta una determinada categoría.

18.14 Tablas descriptivas de la tenencia de la tierra

La variable su_tenencia resulta particularmente relevante en estudios agropecuarios.

base_analitica |>

  mutate(
    porcentaje =
      round(
        n / sum(n) * 100,
        2

    desc(n)
  ) |>
  kable(

La tabla permite identificar las formas predominantes de acceso a la tierra.

18.15 Tablas cruzadas

Las tablas cruzadas permiten analizar simultáneamente dos variables categóricas.

Por ejemplo:

tamano_upa
y
tiene_bosque

18.16 Construcción de una tabla cruzada

table(
  base_analitica$tamano_upa,
  base_analitica$tiene_bosque
) |>
  kable(
    caption = "Tabla cruzada entre tamaño de UPA y presencia de bosque"
  )

La tabla muestra la distribución conjunta de ambas variables.

18.17 Tabla cruzada con porcentajes

También podemos calcular porcentajes por fila.

prop.table(
  table(
    base_analitica$tamano_upa,
    base_analitica$tiene_bosque
  ),
  margin = 1
) |>
  round(3) |>
  kable(
    caption = "Porcentajes por fila para tamaño de UPA y presencia de bosque"
  )

Estos porcentajes facilitan la comparación entre grupos.

18.18 Interpretación de tablas cruzadas

Las tablas cruzadas permiten responder preguntas como:

  • ¿Los productores más grandes presentan mayor presencia de bosque?
  • ¿Existen diferencias entre categorías?
  • ¿Cómo se distribuyen las observaciones entre grupos?

Estas tablas constituyen la base de muchos análisis inferenciales posteriores.

18.19 Buenas prácticas en la construcción de tablas

Al construir tablas descriptivas se recomienda:

  • Utilizar títulos informativos.
  • Mantener un número razonable de decimales.
  • Evitar tablas excesivamente extensas.
  • Ordenar categorías cuando sea pertinente.
  • Presentar porcentajes junto con frecuencias.
  • Incorporar interpretaciones sustantivas.

Estas prácticas mejoran significativamente la comunicación de resultados (Cleveland, 1993).

18.20 Tablas descriptivas ponderadas

En el capítulo anterior aprendimos que las encuestas oficiales utilizan factores de expansión para representar adecuadamente a la población.

En la ESPAC 2025, la variable:

fact_exp_fin

permite extrapolar los resultados de la muestra hacia la población objetivo.

Por esta razón, muchas tablas descriptivas deben construirse utilizando ponderaciones (Groves et al., 2009).

18.21 ¿Por qué ponderar?

Supongamos que queremos estimar la distribución de las unidades productivas según tamaño.

Sin ponderación:

base_analitica |>
  count(
    tamano_upa
  ) |>
  mutate(
    porcentaje =
      round(
        n / sum(n) * 100,
        2
      )
  ) |>
  kable(
    caption = "Distribución no ponderada del tamaño de UPA"
  )

Esta tabla describe únicamente la muestra observada.

18.22 Distribución ponderada

Ahora incorporamos los factores de expansión.

base_analitica |>
  group_by(
    tamano_upa
  ) |>
  summarise(
    expansion =
      sum(
        fact_exp_fin,
        na.rm = TRUE
      )
  ) |>
  mutate(
    porcentaje =
      round(
        expansion /
          sum(expansion) * 100,
        2
      )
  ) |>
  arrange(
    desc(expansion)
  ) |>
  kable(
    digits = 0,
    caption = "Distribución ponderada del tamaño de UPA"
  )

La diferencia entre ambas tablas refleja el efecto del diseño muestral.

18.23 Tablas descriptivas ponderadas por provincia

También podemos estimar la distribución territorial de la población.

base_analitica |>
  group_by(
    provincia
  ) |>
  summarise(
    expansion =
      sum(
        fact_exp_fin,
        na.rm = TRUE
      )
  ) |>
  arrange(
    desc(expansion)
  ) |>
  head(10) |>
  kable(
    digits = 0,
    caption = "Estimación poblacional por provincia"
  )

La tabla muestra las provincias con mayor representación dentro de la población estimada.

18.24 Medias ponderadas

Las ponderaciones también pueden utilizarse para estimar estadísticas descriptivas.

Por ejemplo:

data.frame(
  media_simple =
    mean(
      base_analitica$supertotal,
      na.rm = TRUE
    ),
  media_ponderada =
    weighted.mean(
      base_analitica$supertotal,
      w =
        base_analitica$fact_exp_fin,
      na.rm = TRUE
    )
) |>
  kable(
    digits = 2,
    caption = "Comparación entre media simple y ponderada"
  )

Las diferencias observadas reflejan la importancia de considerar el diseño muestral durante el análisis.

18.25 Tablas profesionales con gt

Aunque kable() resulta muy útil, en proyectos profesionales suele requerirse un nivel adicional de presentación.

Para ello podemos utilizar el paquete gt.

library(gt)

18.26 Primera tabla con gt

base_analitica |>
  count(
    tamano_upa
  ) |>
  gt() |>
  tab_header(
    title =
      "Distribución del tamaño de UPA"
  )

Observe cómo la presentación resulta más elegante y profesional.

18.27 Personalizando títulos

Podemos añadir subtítulos.

base_analitica |>
  count(
    tamano_upa
  ) |>
  gt() |>
  tab_header(
    title =
      "Distribución del tamaño de UPA",
    subtitle =
      "ESPAC 2025"
  )

Esta práctica es particularmente útil en informes institucionales.

18.28 Renombrando columnas

También podemos modificar los encabezados.

base_analitica |>
  count(
    tamano_upa
  ) |>
  gt() |>
  cols_label(
    tamano_upa =
      "Tamaño de UPA",
    n =
      "Frecuencia"
  )

Los nombres descriptivos mejoran considerablemente la legibilidad.

18.29 Formateando números

Las tablas académicas suelen requerir un número consistente de decimales.

data.frame(
  Media =
    mean(
      base_analitica$supertotal,
      na.rm = TRUE
    ),
  Mediana =
    median(
      base_analitica$supertotal,
      na.rm = TRUE
    )
) |>
  gt() |>
  fmt_number(
    decimals = 2
  )

Esta práctica facilita la interpretación de los resultados.

18.30 Tabla descriptiva profesional

Podemos combinar varias estadísticas en una sola tabla.

tabla_descriptiva <-
  data.frame(
    Variable = c(
      "Superficie total",
      "Porcentaje bosque",
      "Factor expansión"
    ),
    Media = c(
      mean(
        base_analitica$supertotal,
        na.rm = TRUE
      ),
      mean(
        base_analitica$pct_bosque,
        na.rm = TRUE
      ),
      mean(
        base_analitica$fact_exp_fin,
        na.rm = TRUE
      )
    ),
    Mediana = c(
      median(
        base_analitica$supertotal,
        na.rm = TRUE
      ),
      median(
        base_analitica$pct_bosque,
        na.rm = TRUE
      ),
      median(
        base_analitica$fact_exp_fin,
        na.rm = TRUE
      )
    )
  )

tabla_descriptiva |>
  gt() |>
  fmt_number(
    columns =
      c(
        Media,
        Mediana
      ),
    decimals = 2
  ) |>
  tab_header(
    title =
      "Tabla descriptiva de variables seleccionadas"
  )

Este tipo de tablas suele encontrarse en artículos científicos y reportes técnicos.

18.31 Exportación de tablas

Una ventaja importante de Quarto es que las tablas se exportan automáticamente.

Al renderizar el documento:

HTML
PDF
Word

las tablas mantienen su estructura y formato.

Por ello no es necesario copiar resultados manualmente desde R hacia procesadores de texto.

18.32 Tablas y reproducibilidad

La construcción automática de tablas constituye uno de los pilares de la investigación reproducible (Gandrud, 2015; Peng, 2011).

Cuando los datos cambian:

Base actualizada
↓
Renderizar nuevamente
↓
Tablas actualizadas

Todo el documento se actualiza automáticamente sin intervención manual.

18.33 Recomendaciones para artículos científicos

Antes de finalizar este capítulo conviene considerar algunas recomendaciones prácticas:

  • Utilizar títulos descriptivos.
  • Incluir unidades de medida cuando corresponda.
  • Limitar el número de decimales.
  • Ordenar categorías lógicamente.
  • Reportar porcentajes junto con frecuencias.
  • Mantener consistencia visual entre tablas.
  • Generar todas las tablas mediante código reproducible.

Estas prácticas mejoran la claridad y credibilidad de los resultados (Healy, 2018).

18.35 Resumen del capítulo

Las tablas descriptivas constituyen una herramienta fundamental para comunicar resultados estadísticos de manera clara, precisa y reproducible.

Durante este capítulo aprendimos a construir tablas para variables numéricas y categóricas, elaborar tablas cruzadas, incorporar factores de expansión y generar presentaciones profesionales utilizando los paquetes kable() y gt.

Estas herramientas permiten transformar resultados estadísticos en evidencia comprensible para investigadores, tomadores de decisiones y lectores especializados.
