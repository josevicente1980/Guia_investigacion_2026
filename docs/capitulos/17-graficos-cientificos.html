20  Gráficos científicos

Objetivos de aprendizaje

Al finalizar este capítulo, el lector será capaz de:

  • Comprender los principios fundamentales de la comunicación visual científica.
  • Diferenciar entre gráficos exploratorios y gráficos destinados a publicación.
  • Aplicar criterios de diseño orientados a la claridad y reproducibilidad.
  • Utilizar temas y escalas apropiadas para artículos científicos, tesis e informes técnicos.
  • Construir gráficos científicamente sólidos utilizando ggplot2.
  • Reconocer errores frecuentes en la comunicación visual de resultados.

20.1 Introducción

La visualización constituye una de las etapas más importantes del análisis estadístico. Un gráfico bien diseñado puede comunicar en segundos patrones que requerirían varias páginas de texto para ser explicados. Sin embargo, no todos los gráficos cumplen el mismo propósito.

Durante las primeras etapas de una investigación suelen utilizarse gráficos exploratorios destinados a comprender los datos. En cambio, cuando los resultados se presentan en una tesis, un informe técnico o un artículo científico, los gráficos deben cumplir estándares adicionales de claridad, precisión y reproducibilidad (Healy, 2018; Wilkinson, 2005).

La visualización científica busca maximizar la comunicación de la información minimizando los elementos innecesarios. Este principio fue ampliamente desarrollado por Tufte (Tufte, 2001), quien argumenta que los gráficos deben enfatizar los datos y reducir los componentes decorativos que no aportan significado analítico.

En este capítulo utilizaremos la base analítica construida a partir de la Encuesta de Superficie y Producción Agropecuaria Continua (ESPAC 2025) para ilustrar los principios de diseño gráfico científico.

library(tidyverse)

base_analitica <- readRDS(

20.4 Preparando variables para visualización

Tal como se observó en el capítulo anterior, la variable supertotal presenta una distribución altamente asimétrica. Por esta razón construiremos una transformación logarítmica que facilite la visualización.

base_analitica <- base_analitica |>
  mutate(
    log_supertotal =
      log1p(
        supertotal
      )
  )

20.5 ¿Qué diferencia un gráfico exploratorio de un gráfico científico?

Los gráficos exploratorios se utilizan durante el análisis para comprender los datos.

Los gráficos científicos tienen un propósito diferente:

  • Comunicar resultados.
  • Facilitar la interpretación.
  • Reducir ambigüedades.
  • Mantener consistencia visual.
  • Garantizar reproducibilidad.
  • Cumplir estándares editoriales.

La siguiente tabla resume las diferencias principales.

comparacion_graficos <- tibble(
  Caracteristica = c(
    "Objetivo",
    "Audiencia",
    "Diseño",
    "Nivel de detalle",
    "Uso principal"
  ),
  Exploratorio = c(
    "Descubrir patrones",
    "Investigador",
    "Flexible",
    "Alto",
    "Análisis"
  ),
  Cientifico = c(
    "Comunicar evidencia",
    "Lectores",
    "Estandarizado",
    "Controlado",
    "Publicación"
  )
)

comparacion_graficos |>
  kable(
    caption = "Comparación entre gráficos exploratorios y científicos"
  )

Interpretación

Los gráficos científicos no sustituyen al análisis exploratorio. Ambos cumplen funciones complementarias dentro del proceso de investigación.

20.6 El principio de la tinta de datos

Tufte (Tufte, 2001) propone que la mayor parte de la tinta utilizada en un gráfico debe estar dedicada a representar información relevante.

Esto implica:

  • Reducir adornos innecesarios.
  • Eliminar fondos excesivos.
  • Evitar efectos tridimensionales.
  • Simplificar rejillas.
  • Destacar los datos.

20.7 Ejemplo de gráfico básico

Comenzaremos con un histograma sencillo.

ggplot(
  base_analitica,
  aes(
    x = log_supertotal
  )
) +
  geom_histogram(
    bins = 30
  )

Interpretación

Aunque el gráfico comunica la distribución de la variable, todavía puede mejorarse desde el punto de vista científico.

20.8 Mejorando la presentación

ggplot(
  base_analitica,
  aes(
    x = log_supertotal
  )
) +
  geom_histogram(
    bins = 30,
    fill = "steelblue",
    color = "white"
  ) +
  theme_minimal() +
  labs(
    x = "Logaritmo de la superficie total",
    y = "Frecuencia"
  )

Interpretación

La versión mejorada reduce el ruido visual y facilita la lectura del gráfico.

20.11 El uso científico del color

El color debe utilizarse para comunicar información y no solamente para decorar.

Un uso adecuado del color permite:

  • Diferenciar categorías.
  • Resaltar patrones.
  • Facilitar comparaciones.
  • Mejorar accesibilidad.

20.12 Paletas perceptualmente uniformes

Las paletas Viridis fueron diseñadas específicamente para visualización científica (Garnier, 2024).

Sus ventajas incluyen:

  • Compatibilidad con impresión.
  • Compatibilidad con escalas de grises.
  • Legibilidad para personas con daltonismo.
  • Gradientes perceptualmente uniformes.

20.13 Ejemplo utilizando Viridis

ggplot(
  base_analitica,
  aes(
    x = tamano_upa,
    fill = tamano_upa
  )
) +
  geom_bar() +
  scale_fill_viridis_d() +
  theme_minimal() +
  labs(
    x = "Tamaño de UPA",
    y = "Frecuencia",
    fill = "Tamaño"
  )

Interpretación

La paleta mantiene contraste adecuado entre categorías y conserva una apariencia profesional.

20.14 Evitando gráficos engañosos

Los gráficos pueden inducir interpretaciones erróneas cuando:

  • Se modifican escalas de manera inapropiada.
  • Se utilizan ejes truncados sin justificación.
  • Se exageran diferencias pequeñas.
  • Se utilizan efectos tridimensionales.

La comunicación científica exige representar los datos de forma honesta y transparente (Cairo, 2016).

20.15 Ejemplo de mala práctica

datos_ejemplo <- tibble(
  grupo = c(
    "A",
    "B"
  ),
  valor = c(
    100,
    105
  )
)

ggplot(
  datos_ejemplo,
  aes(
    x = grupo,
    y = valor
  )
) +
  geom_col(
    fill = "firebrick"
  ) +
  coord_cartesian(
    ylim = c(
      95,
      106
    )
  ) +
  theme_minimal()

Interpretación

El gráfico exagera visualmente una diferencia relativamente pequeña. Este tipo de prácticas debe evitarse en publicaciones científicas.

20.16 Ejemplo corregido

ggplot(
  datos_ejemplo,
  aes(
    x = grupo,
    y = valor
  )
) +
  geom_col(
    fill = "steelblue"
  ) +
  theme_minimal()

Interpretación

La representación correcta permite apreciar la verdadera magnitud de la diferencia observada.

20.17 Construyendo un estilo gráfico reproducible

Una práctica recomendable consiste en definir un estilo gráfico común para toda la investigación.

tema_cientifico <- theme_minimal() +
  theme(
    plot.title =
      element_text(
        face = "bold"
      ),
    axis.title =
      element_text(
        face = "bold"
      ),
    legend.title =
      element_text(
        face = "bold"
      )
  )

20.19 Recomendaciones para publicaciones científicas

Al construir figuras destinadas a publicaciones se recomienda:

  • Mantener consistencia visual.
  • Utilizar tipografías legibles.
  • Evitar colores innecesarios.
  • Reducir ruido visual.
  • Incluir títulos y etiquetas claras.
  • Garantizar reproducibilidad.
  • Conservar una misma línea gráfica en todo el documento.

21 Parte 2. Gráficos científicos para tesis, informes y artículos

21.1 Introducción

En la sección anterior aprendimos los principios fundamentales de la comunicación visual científica. Sin embargo, la calidad de una figura no depende únicamente de su apariencia estética. Los gráficos utilizados en tesis, artículos científicos e informes técnicos deben facilitar la interpretación estadística de los resultados y comunicar evidencia de manera clara y precisa (Cairo, 2016; Tufte, 2001).

En esta sección construiremos figuras que suelen encontrarse en publicaciones académicas, incorporando criterios de presentación utilizados habitualmente en revistas científicas.

21.2 Histograma publicable

Comenzaremos construyendo una versión mejorada del histograma de superficie transformada.

ggplot(
  base_analitica,
  aes(
    x = log_supertotal
  )
) +
  geom_histogram(
    bins = 35,
    fill = "#2C7FB8",
    color = "white"
  ) +
  tema_cientifico +
  labs(
    title = "Distribución de la superficie total",
    subtitle = "Variable transformada mediante logaritmo natural",
    x = "Logaritmo de la superficie total",
    y = "Frecuencia"
  )

Interpretación

La transformación logarítmica mejora significativamente la capacidad de visualizar la distribución de la superficie agrícola, reduciendo la influencia de observaciones extremadamente grandes.

21.3 Histograma con densidad

En muchas publicaciones científicas se recomienda complementar el histograma con una curva de densidad.

ggplot(
  base_analitica,
  aes(
    x = log_supertotal
  )
) +
  geom_histogram(
    aes(
      y = after_stat(density)
    ),
    bins = 35,
    fill = "gray80",
    color = "white"
  ) +
  geom_density(
    linewidth = 1,
    color = "#08519C"
  ) +
  tema_cientifico +
  labs(
    x = "Logaritmo de la superficie total",
    y = "Densidad"
  )

Interpretación

La curva de densidad permite identificar de forma más clara la forma general de la distribución y posibles concentraciones de observaciones.

21.4 Comparaciones mediante diagramas de caja

Los diagramas de caja constituyen una de las herramientas más utilizadas para comparar distribuciones entre grupos.

ggplot(
  base_analitica,
  aes(
    x = tamano_upa,
    y = log_supertotal,
    fill = tamano_upa
  )
) +
  geom_boxplot(
    alpha = 0.8
  ) +
  scale_fill_viridis_d() +
  tema_cientifico +
  labs(
    x = "Tamaño de UPA",
    y = "Logaritmo de la superficie total",
    fill = "Tamaño"
  )

Interpretación

Las diferencias observadas entre cajas sugieren heterogeneidad en la distribución de la superficie según el tamaño de la unidad productiva.

21.5 Gráficos de violín

Los gráficos de violín combinan características de los diagramas de caja y de las curvas de densidad.

ggplot(

  ) +

Interpretación

La anchura de cada violín representa la concentración relativa de observaciones en distintos niveles de la variable.

21.6 Barras con intervalos de confianza

Los artículos científicos suelen presentar estimaciones acompañadas por medidas de incertidumbre.

Primero calcularemos la superficie promedio por categoría.

resumen_tamano <- base_analitica |>
  group_by(
    tamano_upa
  ) |>
  summarise(
    media =
      mean(
        log_supertotal,
        na.rm = TRUE
      ),
    sd =
      sd(
        log_supertotal,
        na.rm = TRUE
      ),
    n =
      n(),
    se =
      sd / sqrt(n),
    li =
      media - 1.96 * se,
    ls =
      media + 1.96 * se,
    .groups = "drop"
  )

resumen_tamano |>
  kable(
    digits = 3,
    caption = "Estadísticos descriptivos por tamaño de UPA"
  )

Interpretación

La tabla resume medias, errores estándar e intervalos de confianza aproximados para cada categoría.

21.7 Barras con intervalos

ggplot(
  resumen_tamano,
  aes(
    x = tamano_upa,
    y = media
  )
) +
  geom_col(
    fill = "#2C7FB8"
  ) +
  geom_errorbar(
    aes(
      ymin = li,
      ymax = ls
    ),
    width = 0.15
  ) +
  tema_cientifico +
  labs(
    x = "Tamaño de UPA",
    y = "Media de log_supertotal"
  )

Interpretación

Los intervalos de confianza proporcionan información sobre la incertidumbre asociada a las estimaciones promedio.

21.8 Gráficos de dispersión para publicaciones

Los gráficos de dispersión suelen utilizarse para explorar asociaciones entre variables cuantitativas.

ggplot(
  base_analitica,
  aes(
    x = log_supertotal,
    y = fact_exp_fin
  )
) +
  geom_point(
    alpha = 0.25,
    color = "#2C7FB8"
  ) +
  geom_smooth(
    method = "lm",
    color = "#D95F0E",
    linewidth = 1
  ) +
  tema_cientifico +
  labs(
    x = "Logaritmo de la superficie total",
    y = "Factor de expansión"
  )

Interpretación

La línea ajustada permite visualizar la tendencia promedio observada entre ambas variables.

21.9 Facetas científicas

Las facetas permiten dividir la información en paneles comparables.

ggplot(
  base_analitica,
  aes(
    x = log_supertotal
  )
) +
  geom_histogram(
    bins = 20,
    fill = "#2C7FB8",
    color = "white"
  ) +
  facet_wrap(
    ~ provincia
  ) +
  tema_cientifico +
  labs(
    x = "Logaritmo de la superficie total",
    y = "Frecuencia"
  )

Interpretación

Las facetas permiten comparar distribuciones territoriales manteniendo la misma escala visual.

21.10 Importancia de las etiquetas

Un gráfico científico debe ser comprensible sin necesidad de consultar el texto principal.

Las etiquetas deben:

  • Describir claramente las variables.
  • Utilizar unidades cuando corresponda.
  • Evitar abreviaturas ambiguas.
  • Mantener consistencia terminológica.

21.11 Ejemplo de etiquetado profesional

ggplot(
  base_analitica,
  aes(
    x = log_supertotal
  )
) +
  geom_histogram(
    bins = 30,
    fill = "#2C7FB8",
    color = "white"
  ) +
  tema_cientifico +
  labs(
    title = "Distribución de la superficie agrícola",
    subtitle = "ESPAC 2025",
    x = "Logaritmo natural de la superficie total (ha)",
    y = "Número de observaciones",
    caption = "Fuente: ESPAC 2025"
  )

Interpretación

Los títulos, subtítulos y etiquetas ayudan al lector a comprender el contenido de la figura sin necesidad de información adicional.

21.12 Escalas y formatos numéricos

Los gráficos científicos deben utilizar formatos numéricos consistentes.

ggplot(
  resumen_tamano,
  aes(
    x = tamano_upa,
    y = media
  )
) +
  geom_col(
    fill = "#2C7FB8"
  ) +
  scale_y_continuous(
    labels = scales::number_format(
      accuracy = 0.01
    )
  ) +
  tema_cientifico +
  labs(
    x = "Tamaño de UPA",
    y = "Media"
  )

Interpretación

La estandarización de escalas mejora la consistencia visual y facilita comparaciones entre figuras.

21.13 Leyendas y consistencia gráfica

Las leyendas deben mantenerse simples y claras.

Se recomienda:

  • Utilizar el mismo esquema de colores en todo el documento.
  • Mantener la misma tipografía.
  • Evitar leyendas redundantes.
  • Utilizar títulos descriptivos.

21.14 Recomendaciones para tesis y artículos

22 Parte 3. Figuras avanzadas para publicaciones científicas

22.1 Introducción

Los artículos científicos, tesis doctorales, informes técnicos y documentos institucionales suelen requerir figuras más complejas que las utilizadas durante el análisis exploratorio. En estos contextos, no basta con construir gráficos individuales; es necesario diseñar figuras coherentes, comparables y reproducibles que comuniquen múltiples resultados de manera integrada (Tufte, 2001; Wilkinson, 2005).

En esta sección aprenderemos a construir figuras multipanel, preparar gráficos para revistas científicas y exportar resultados utilizando estándares reproducibles.

22.2 ¿Qué es una figura científica avanzada?

Una figura científica avanzada suele presentar:

  • Varias visualizaciones relacionadas.
  • Una narrativa gráfica coherente.
  • Comparaciones simultáneas.
  • Escalas consistentes.
  • Diseño uniforme.
  • Preparación para publicación.

La Figura compuesta es uno de los formatos más utilizados en artículos científicos.

22.3 Construyendo una colección de gráficos

Primero construiremos varios gráficos que posteriormente integraremos en una figura compuesta.

22.4 Figuras multipanel

Los artículos científicos suelen combinar múltiples gráficos dentro de una misma figura.

Para ello utilizaremos el paquete patchwork.

library(patchwork)

22.5 Construcción de una figura compuesta

(
  grafico_histograma +
  grafico_boxplot
) /
(
  grafico_dispersion
)

Interpretación

La figura integra diferentes perspectivas del mismo fenómeno, facilitando la comparación visual y reduciendo el número de imágenes necesarias en un artículo.

22.6 Organización visual de paneles

Las figuras multipanel permiten:

  • Reducir espacio.
  • Comparar resultados.
  • Mostrar evidencia complementaria.
  • Mejorar la narrativa gráfica.

Este tipo de figuras es particularmente frecuente en revistas indexadas.

22.9 Resolución y calidad gráfica

La calidad de una figura depende de:

  • Resolución.
  • Formato.
  • Tamaño físico.
  • Legibilidad.

Las revistas científicas suelen solicitar resoluciones entre 300 y 600 dpi (Wilke, 2019).

22.13 Integración con Quarto

Una ventaja importante de Quarto es que las figuras se generan automáticamente durante el proceso de renderización.

Esto permite:

  • Reproducibilidad completa.
  • Actualización automática.
  • Consistencia visual.
  • Menor riesgo de errores.

22.14 Reproducibilidad gráfica

La reproducibilidad implica que cualquier investigador pueda reconstruir exactamente la misma figura utilizando:

  • Los mismos datos.
  • El mismo código.
  • El mismo entorno analítico.

La visualización reproducible constituye un componente esencial de la ciencia abierta (Peng, 2011).

22.16 Errores frecuentes

Entre los errores más comunes se encuentran:

  • Uso excesivo de colores.
  • Texto demasiado pequeño.
  • Escalas inconsistentes.
  • Gráficos tridimensionales innecesarios.
  • Exportación en baja resolución.
  • Falta de reproducibilidad.
