25  Diagnóstico del modelo

Objetivos de aprendizaje

Al finalizar esta sección, el lector será capaz de:

  • Comprender el propósito del diagnóstico de modelos.
  • Interpretar residuos de regresión.
  • Evaluar linealidad.
  • Evaluar normalidad de residuos.
  • Evaluar homogeneidad de varianza.
  • Identificar señales tempranas de problemas de especificación.

25.1 Introducción

La estimación de una regresión no constituye el final del análisis.

Una vez ajustado un modelo es necesario verificar si sus supuestos básicos resultan razonables. El incumplimiento de estos supuestos puede afectar la validez de las inferencias, los intervalos de confianza y las predicciones (Montgomery et al., 2021).

En este capítulo utilizaremos el modelo múltiple construido previamente para ilustrar las principales herramientas de diagnóstico.

25.7 ¿Qué son los residuos?

Los residuos representan la diferencia entre los valores observados y los valores predichos.

Formalmente:

\[e_i = y_i - \hat{y}_i\]

Un buen modelo produce residuos pequeños y sin patrones sistemáticos.

25.8 Construcción de residuos

base_modelo <- base_modelo |>
  mutate(
    ajustado =
      fitted(
        modelo_diag
      ),
    residuo =
      residuals(
        modelo_diag
      )
  )

25.21 Introducción

En la sección anterior evaluamos la distribución de los residuos y verificamos los supuestos básicos del modelo lineal.

Ahora analizaremos tres aspectos adicionales que pueden afectar la calidad de una regresión múltiple:

  • Multicolinealidad.
  • Observaciones influyentes.
  • Leverage.

Estos elementos son especialmente importantes cuando se trabaja con múltiples variables explicativas (Montgomery et al., 2021).

25.26 ¿Qué es la multicolinealidad?

La multicolinealidad aparece cuando dos o más variables explicativas contienen información muy similar.

Conceptualmente:

X1  ↔  X2

Si ambas variables aportan prácticamente la misma información, la estimación de los coeficientes puede volverse inestable.

25.27 Consecuencias de la multicolinealidad

La multicolinealidad puede provocar:

  • Coeficientes poco estables.
  • Errores estándar elevados.
  • Intervalos de confianza amplios.
  • Dificultades de interpretación.

No afecta necesariamente la capacidad predictiva del modelo, pero sí puede dificultar la interpretación individual de los coeficientes.

25.28 Factor de inflación de la varianza (VIF)

La medida más utilizada para evaluar multicolinealidad es el Variance Inflation Factor (VIF).

vif_valores <- car::vif(
  modelo_diag
)

if (
  is.matrix(
    vif_valores
  )
) {
  vif_tabla <- as.data.frame(
    vif_valores
  ) |>
    tibble::rownames_to_column(
      "Variable"
    )
} else {
  vif_tabla <- tibble(
    Variable =
      names(
        vif_valores
      ),
    VIF =
      as.numeric(
        vif_valores
      )
  )
}

vif_tabla |>
  kable(
    digits = 3,
    caption = "Factores de inflación de la varianza"
  )

Interpretación

Como regla práctica:

VIF < 5
Multicolinealidad baja

VIF entre 5 y 10
Posible preocupación

VIF > 10
Problema importante

25.29 Visualización de VIF

vif_tabla |>
  mutate(
    VIF_grafico =
      ifelse(
        "GVIF^(1/(2*Df))" %in% names(
          vif_tabla
        ),
        `GVIF^(1/(2*Df))`,
        VIF
      )
  ) |>
  ggplot(
    aes(
      x = reorder(
        Variable,

      ),
      y = VIF_grafico
    )
  ) +
  geom_col(
    fill = "steelblue"

  labs(
    x = "Variable",
    y = "VIF"
  )

Interpretación

El gráfico facilita identificar qué variables presentan mayores niveles de colinealidad.

25.30 ¿Qué es una observación influyente?

Una observación influyente es aquella que tiene capacidad para modificar significativamente los resultados del modelo.

No todas las observaciones extremas son necesariamente influyentes.

25.31 Distancia de Cook

La Distancia de Cook es una de las medidas más utilizadas para identificar observaciones influyentes.

base_modelo <- base_modelo |>

25.35 ¿Qué es el leverage?

El leverage mide qué tan alejadas se encuentran las observaciones respecto al centro de la nube de datos explicativos.

Observaciones con leverage elevado tienen mayor capacidad para influir en el ajuste.

25.39 Influencia versus leverage

No todas las observaciones con leverage alto son influyentes.

Tampoco todas las observaciones influyentes presentan leverage elevado.

Por ello es recomendable analizar simultáneamente:

  • Residuos.
  • Leverage.
  • Distancia de Cook.

25.52 Identificación automática de casos a revisar

base_modelo |>
  mutate(
    id = row_number()
  ) |>
  filter(
    abs(
      residuo_std
    ) > 2 |
    cook > 4 / nrow(
      base_modelo
    )
  ) |>
  select(
    id,
    residuo_std,
    leverage,
    cook
  ) |>
  slice_head(

25.57 Aplicación práctica

Antes de reportar resultados de una regresión:

  1. Revise los residuos.
  2. Analice el gráfico Q-Q.
  3. Evalúe homoscedasticidad.
  4. Calcule VIF.
  5. Revise leverage.
  6. Analice Distancia de Cook.
  7. Identifique observaciones atípicas.
  8. Verifique la estabilidad de los coeficientes.
  9. Documente limitaciones.
  10. Interprete resultados únicamente después de completar el diagnóstico.

25.58 Manos a la obra

  1. Estime una regresión múltiple.
  2. Construya residuos.
  3. Evalúe linealidad.
  4. Evalúe normalidad.
  5. Evalúe homoscedasticidad.
  6. Calcule VIF.
  7. Obtenga leverage.
  8. Calcule Distancia de Cook.
  9. Identifique observaciones influyentes.
  10. Elabore un informe de validación del modelo.

25.59 Resumen del capítulo

En este capítulo aprendimos a validar modelos de regresión mediante herramientas diagnósticas fundamentales.

Primero analizamos residuos, linealidad, normalidad y homoscedasticidad. Posteriormente estudiamos multicolinealidad mediante VIF e identificamos observaciones influyentes utilizando leverage y Distancia de Cook. Finalmente integramos todos los diagnósticos en un procedimiento sistemático de validación.

El diagnóstico constituye una etapa indispensable dentro de cualquier análisis estadístico porque permite evaluar la confiabilidad de las inferencias y la calidad de las predicciones generadas por el modelo.
