34  Discusión

Objetivos de aprendizaje

Al finalizar este capítulo, el lector será capaz de:

  • Comprender la función de la discusión dentro de un documento científico.
  • Diferenciar resultados y discusión.
  • Interpretar hallazgos a la luz de la literatura científica.
  • Identificar implicaciones teóricas y prácticas.
  • Redactar una discusión reproducible y argumentativamente sólida.

34.1 Introducción

La discusión constituye el espacio donde el investigador interpreta los resultados obtenidos y los relaciona con el conocimiento existente.

Mientras la sección de resultados responde a la pregunta “¿qué encontramos?”, la discusión responde a la pregunta “¿qué significan estos hallazgos?” (American Psychological Association, 2020).

Una buena discusión conecta los resultados con la teoría, la evidencia previa y las implicaciones derivadas del estudio (Belcher, 2019).

34.2 Configuración inicial

34.2.1 Carga de librerías

library(tidyverse)
library(gapminder)
library(knitr)
library(broom)

34.2.2 Carga de datos

data(
  "gapminder",
  package = "gapminder"
)

datos_discusion <- gapminder

34.3 Recuperando resultados para discutir

La discusión siempre debe construirse a partir de resultados previamente obtenidos.

modelo_discusion <- lm(
  lifeExp ~ log(gdpPercap),
  data = datos_discusion
)
broom::tidy(
  modelo_discusion
) |>
  kable(
    digits = 4,
    caption = "Resultados utilizados para la discusión"
  )

Interpretación

Los coeficientes constituyen la evidencia empírica que servirá de base para la construcción de la discusión.

34.4 Del resultado a la interpretación

34.4.1 Resultado

El coeficiente asociado al PIB per cápita es positivo y estadísticamente significativo.

34.4.2 Discusión

Este resultado sugiere que mayores niveles de ingreso se encuentran asociados con una mayor esperanza de vida. El hallazgo coincide con investigaciones previas que identifican al desarrollo económico como un determinante importante del bienestar poblacional (Deaton, 2013).

Interpretación

La discusión no repite números. Explica el significado de los hallazgos.

34.5 Comparación con estudios previos

Una función central de la discusión consiste en contrastar los resultados con la literatura existente.

tibble(
  Aspecto = c(
    "Resultado propio",
    "Literatura previa",
    "Coincidencia"
  ),
  Descripcion = c(
    "Relación positiva",
    "Relación positiva",
    "Sí"
  )
) |>
  kable(
    caption = "Comparación conceptual con estudios previos"
  )

Interpretación

La discusión debe indicar si los resultados respaldan, amplían o contradicen investigaciones anteriores.

34.6 Identificación de aportes

Después de comparar resultados, debe explicarse la contribución específica del estudio.

tibble(
  Tipo = c(
    "Empírico",
    "Metodológico",
    "Aplicado"
  ),
  Descripcion = c(
    "Genera evidencia",
    "Aplica técnicas reproducibles",
    "Apoya decisiones"
  )
) |>
  kable(
    caption = "Tipos de contribución científica"
  )

Interpretación

Todo estudio debe explicar explícitamente cuál es su aporte al conocimiento existente.

34.7 Implicaciones prácticas

La discusión también debe identificar posibles aplicaciones de los resultados.

tibble(
  Hallazgo = c(
    "Mayor ingreso",
    "Mayor esperanza de vida"
  ),
  Implicacion = c(
    "Promoción del crecimiento económico",
    "Mejora del bienestar"
  )
) |>
  kable(
    caption = "Ejemplo de implicaciones prácticas"
  )

Interpretación

Las implicaciones ayudan a conectar la investigación con la toma de decisiones.

34.8 Limitaciones del estudio

Toda discusión debe reconocer las limitaciones existentes.

tibble(
  Limitacion = c(
    "Variables omitidas",
    "Datos observacionales",
    "Cobertura temporal"
  )
) |>
  kable(
    caption = "Limitaciones potenciales"
  )

Interpretación

Reconocer limitaciones fortalece la credibilidad del trabajo científico.

34.9 Propuestas para futuras investigaciones

Las limitaciones identificadas suelen convertirse en oportunidades para nuevas investigaciones.

tibble(
  Propuesta = c(
    "Nuevas variables",
    "Datos longitudinales",
    "Modelos alternativos"
  )
) |>
  kable(
    caption = "Líneas futuras de investigación"
  )

Interpretación

Las investigaciones científicas generan nuevas preguntas además de responder las existentes.

34.10 Estructura recomendada para la discusión

Resultado principal

↓

Interpretación

↓

Comparación con literatura

↓

Aporte del estudio

↓

Implicaciones

↓

Limitaciones

↓

Investigaciones futuras

34.11 Ejemplo de redacción adecuada

Los resultados obtenidos evidencian una asociación positiva entre ingreso y esperanza de vida. Este hallazgo coincide con estudios previos que destacan el papel del desarrollo económico en la mejora de las condiciones de bienestar (Deaton, 2013). La evidencia presentada amplía la comprensión de esta relación utilizando procedimientos completamente reproducibles. Desde una perspectiva aplicada, los resultados sugieren que políticas orientadas al crecimiento económico podrían contribuir indirectamente a mejorar indicadores de salud poblacional. No obstante, deben considerarse limitaciones relacionadas con la disponibilidad de variables adicionales y la naturaleza observacional de los datos utilizados.

34.12 Errores frecuentes

34.12.1 Incorrecto

El coeficiente fue 3.25 y el valor p fue menor que 0.05.

Esto pertenece a resultados.

34.12.2 Correcto

La evidencia respalda la existencia de una asociación positiva entre las variables analizadas.

Esto corresponde a discusión.

34.13 Lista de verificación

tibble(
  Elemento = c(
    "Interpretación",
    "Literatura",
    "Aportes",
    "Implicaciones",
    "Limitaciones",
    "Investigación futura"
  ),
  Verificado = c(
    "Sí",
    "Sí",
    "Sí",
    "Sí",
    "Sí",
    "Sí"
  )
) |>
  kable(
    caption = "Lista de verificación de la discusión"
  )

Interpretación

Antes de finalizar un manuscrito es recomendable verificar que todos los componentes fundamentales de la discusión estén presentes.

34.14 Manos a la obra

  1. Identifique el hallazgo principal.
  2. Interprete su significado.
  3. Compare el resultado con la literatura.
  4. Explique la contribución del estudio.
  5. Analice implicaciones prácticas.
  6. Reconozca limitaciones.
  7. Proponga investigaciones futuras.
  8. Evite repetir tablas y coeficientes.
  9. Mantenga coherencia con los objetivos.
  10. Revise la lógica argumentativa.

34.15 Resumen del capítulo

En este capítulo se estudió la función de la discusión dentro de un documento científico. Se mostró cómo interpretar resultados, compararlos con la literatura existente, identificar aportes, reconocer limitaciones y proponer futuras líneas de investigación. Una discusión sólida transforma resultados estadísticos en conocimiento científico útil y contextualizado.
