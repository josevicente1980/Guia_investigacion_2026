19  Visualización de datos

Objetivos de aprendizaje

Al finalizar este capítulo, el lector será capaz de:

  • Comprender la importancia de la visualización dentro del análisis exploratorio de datos.
  • Construir gráficos reproducibles utilizando ggplot2.
  • Representar distribuciones mediante histogramas y curvas de densidad.
  • Aplicar transformaciones simples para mejorar la visualización de variables asimétricas.
  • Comparar grupos utilizando gráficos de barras y diagramas de caja.
  • Interpretar correctamente diferentes tipos de visualizaciones estadísticas.
  • Aplicar buenas prácticas en la comunicación visual de resultados.

19.1 Introducción

La visualización de datos constituye una de las herramientas más importantes dentro del análisis estadístico moderno. Mientras que las tablas permiten resumir información numérica, los gráficos facilitan la identificación de patrones, tendencias, valores atípicos y relaciones entre variables de forma mucho más intuitiva (Wickham, 2016).

En investigación científica, la visualización no debe entenderse únicamente como un elemento estético. Un gráfico correctamente diseñado permite explorar los datos, generar hipótesis y comunicar resultados de manera clara y efectiva (Wilkinson, 2005).

La visualización constituye además uno de los pilares del análisis exploratorio de datos, ya que permite comprender la estructura de una base antes de aplicar procedimientos estadísticos más complejos (Healy, 2018).

En este capítulo utilizaremos la base analítica construida a partir de la Encuesta de Superficie y Producción Agropecuaria Continua (ESPAC 2025).

Interpretación

19.4 Preparando una variable transformada

La variable supertotal representa la superficie total de la unidad productiva agropecuaria. Como suele ocurrir con variables agrarias, su distribución puede ser altamente asimétrica: muchas unidades tienen superficies pequeñas y pocas unidades presentan superficies muy grandes.

Para visualizar mejor esta variable utilizaremos una transformación logarítmica:

log_supertotal = log(supertotal + 1)

La función log1p() calcula precisamente log(x + 1), evitando problemas cuando existen valores iguales a cero.

base_analitica <- base_analitica |>
  mutate(
    log_supertotal =
      log1p(
        supertotal
      )
  )

19.5 Resumen estadístico previo

Antes de construir gráficos resulta útil examinar algunas estadísticas descriptivas de la variable original y de su versión transformada.

data.frame(
  Variable = c(
    "supertotal",
    "log_supertotal"
  ),
  Minimo = c(
    min(
      base_analitica$supertotal,
      na.rm = TRUE
    ),
    min(
      base_analitica$log_supertotal,
      na.rm = TRUE
    )
  ),
  Mediana = c(
    median(
      base_analitica$supertotal,
      na.rm = TRUE
    ),
    median(
      base_analitica$log_supertotal,
      na.rm = TRUE
    )
  ),
  Media = c(
    mean(
      base_analitica$supertotal,
      na.rm = TRUE
    ),
    mean(
      base_analitica$log_supertotal,
      na.rm = TRUE
    )
  ),
  Maximo = c(
    max(
      base_analitica$supertotal,
      na.rm = TRUE
    ),
    max(
      base_analitica$log_supertotal,
      na.rm = TRUE
    )
  )
) |>
  kable(
    digits = 2,
    caption = "Resumen de superficie total original y transformada"
  )

Interpretación

La variable original presenta una diferencia muy amplia entre la mediana y el valor máximo. La transformación logarítmica reduce la escala de los valores extremos y permite visualizar mejor la distribución general de la superficie.

19.6 ¿Por qué visualizar datos?

Las visualizaciones permiten:

  • Identificar patrones.
  • Detectar valores extremos.
  • Comprender distribuciones.
  • Comparar grupos.
  • Comunicar resultados.
  • Generar hipótesis de investigación.

Por ejemplo, una tabla puede indicar que una variable presenta una media elevada, pero únicamente un gráfico permite comprender cómo se distribuyen realmente las observaciones.

19.7 La gramática de los gráficos

El paquete ggplot2 se basa en la denominada Gramática de los Gráficos propuesta por Wilkinson (Wilkinson, 2005).

La lógica general consiste en combinar:

Datos
+
Variables
+
Geometrías
+
Escalas
+
Temas
=
Gráfico

La estructura básica de un gráfico en ggplot2 es:

ggplot(
  datos,
  aes(
    x = variable_x,
    y = variable_y
  )
) +
  geom_tipo()

Esta sintaxis será utilizada a lo largo de todo el capítulo.

19.8 Distribuciones de variables cuantitativas

Uno de los primeros objetivos del análisis exploratorio consiste en comprender cómo se distribuyen las variables numéricas.

En nuestro caso utilizaremos log_supertotal, que permite observar mejor la forma de la distribución de la superficie total.

19.9 Histograma de la superficie transformada

El histograma constituye una de las herramientas más utilizadas para representar distribuciones cuantitativas (Wilkinson, 2005).

ggplot(
  base_analitica,
  aes(
    x = log_supertotal
  )
) +
  geom_histogram(
    bins = 30,
    fill = "steelblue",
    color = "white"
  ) +
  theme_minimal() +
  labs(
    x = "Logaritmo de la superficie total",
    y = "Frecuencia"
  )

Interpretación

La transformación logarítmica permite observar una distribución mucho más informativa. En lugar de concentrar casi todas las observaciones en el extremo izquierdo, el gráfico muestra con mayor claridad cómo se distribuyen las unidades productivas.

19.10 Curvas de densidad

Las curvas de densidad representan una versión suavizada de la distribución observada (Wickham, 2016).

ggplot(
  base_analitica,
  aes(
    x = log_supertotal
  )
) +
  geom_density(
    fill = "lightblue",
    alpha = 0.6
  ) +
  theme_minimal() +
  labs(
    x = "Logaritmo de la superficie total",
    y = "Densidad"
  )

Interpretación

La densidad suavizada muestra la forma general de la distribución transformada y facilita la identificación de concentraciones de observaciones.

19.11 Histograma y densidad combinados

Una práctica frecuente consiste en combinar ambas representaciones.

ggplot(
  base_analitica,
  aes(
    x = log_supertotal
  )
) +
  geom_histogram(
    aes(
      y = after_stat(density)
    ),
    bins = 30,
    fill = "lightgray",
    color = "white"
  ) +
  geom_density(
    linewidth = 1
  ) +
  theme_minimal() +
  labs(
    x = "Logaritmo de la superficie total",
    y = "Densidad"
  )

Interpretación

La combinación del histograma y la curva de densidad permite comparar las frecuencias observadas con la forma suavizada de la distribución.

19.18 Relaciones entre variables

En la primera parte del capítulo aprendimos a visualizar distribuciones y comparar grupos. Sin embargo, muchas preguntas de investigación requieren analizar relaciones entre dos o más variables.

Por ejemplo, podríamos preguntarnos:

  • ¿Existe relación entre la superficie total y el factor de expansión?
  • ¿Los distintos tamaños de UPA presentan patrones visuales diferentes?
  • ¿Existen diferencias territoriales en la distribución de la superficie?
  • ¿Qué combinaciones de categorías son más frecuentes?

Las visualizaciones bivariadas y multivariadas permiten explorar estas preguntas antes de aplicar modelos estadísticos más complejos (Healy, 2018; Wilkinson, 2005).

19.19 Gráficos de dispersión

Los gráficos de dispersión permiten representar la relación entre dos variables numéricas.

En este caso analizaremos:

log_supertotal
y
fact_exp_fin

La primera variable representa la superficie total transformada mediante logaritmo, mientras que la segunda corresponde al factor de expansión de la encuesta.

ggplot(
  base_analitica,
  aes(
    x = log_supertotal,
    y = fact_exp_fin
  )
) +
  geom_point(
    alpha = 0.3
  ) +
  theme_minimal() +
  labs(
    x = "Logaritmo de la superficie total",
    y = "Factor de expansión"
  )

Interpretación

Cada punto representa una observación de la base analítica. El gráfico permite explorar si existe algún patrón visual entre la superficie total transformada y el factor de expansión.

19.20 Línea de tendencia

Una línea de tendencia permite resumir visualmente la relación promedio entre dos variables.

ggplot(
  base_analitica,
  aes(
    x = log_supertotal,
    y = fact_exp_fin
  )
) +
  geom_point(
    alpha = 0.25
  ) +
  geom_smooth(
    method = "lm",
    se = TRUE
  ) +
  theme_minimal() +
  labs(
    x = "Logaritmo de la superficie total",
    y = "Factor de expansión"
  )

Interpretación

La línea de tendencia permite observar la dirección general de la relación. Esta visualización no debe interpretarse como evidencia causal, sino como una primera exploración descriptiva.

ggplot(

Interpretación

El gráfico representa simultáneamente la superficie transformada, el factor de expansión, el tamaño del punto y la categoría de tamaño de UPA. Aunque este tipo de gráfico puede ser visualmente atractivo, debe usarse con cuidado para no sobrecargar la interpretación.

19.31 Buenas prácticas para visualizaciones multivariadas

Las visualizaciones multivariadas pueden ser muy útiles, pero también pueden volverse confusas si se incorporan demasiadas dimensiones al mismo tiempo.

Se recomienda:

  • Incorporar variables gradualmente.
  • Utilizar colores solo cuando aporten información.
  • Evitar gráficos excesivamente saturados.
  • Mantener etiquetas claras.
  • Interpretar los patrones con cautela.
  • No confundir asociación visual con causalidad.

La visualización debe ayudar a comprender los datos, no complicar innecesariamente su lectura (Healy, 2018).

19.32 Visualizaciones territoriales: de tablas planas a mapas inteligentes

Los datos territoriales permiten pasar de una tabla tradicional a una representación espacial del fenómeno estudiado. Cuando una base contiene provincias, cantones, coordenadas o cualquier referencia geográfica, es posible construir mapas que ayuden a identificar patrones regionales, concentraciones y diferencias espaciales (Lovelace et al., 2019).

En esta sección construiremos una introducción práctica al análisis espacial en R utilizando Ecuador como referencia. El objetivo no es desarrollar todavía un análisis espacial avanzado, sino comprender la lógica básica de los mapas estáticos, los puntos georreferenciados, los sistemas de coordenadas, los buffers y los mapas interactivos.

19.33 Preparación del laboratorio espacial

Para trabajar con datos espaciales utilizaremos sf, que permite manejar geometrías geográficas, y leaflet, que permite construir mapas interactivos. Para asegurar que el capítulo se renderice correctamente en HTML, Word y PDF, los mapas interactivos se mostrarán solo cuando el formato de salida sea HTML. En Word y PDF se mostrará una versión estática.

library(sf)
library(leaflet)
library(maps)

19.52 ¿Mapa estático o mapa dinámico?

Un mapa estático es como una fotografía: el investigador controla completamente el diseño final. Es ideal para tesis, artículos, documentos PDF e informes impresos.

Un mapa dinámico es una experiencia interactiva: el lector decide qué explorar. Es ideal para reportes HTML, tableros de control y productos digitales.

Ambos tipos de mapas son útiles. La elección depende del objetivo de comunicación y del formato final del documento.

19.53 Buenas prácticas para visualización espacial

Al construir mapas se recomienda:

  • Usar sistemas de coordenadas adecuados.
  • Verificar que las capas compartan el mismo CRS.
  • Evitar medir distancias en grados.
  • Transformar los datos antes de construir buffers.
  • No saturar el mapa con demasiadas etiquetas.
  • Usar mapas dinámicos solo cuando la interacción aporte valor.
  • Acompañar los mapas con una interpretación clara.
